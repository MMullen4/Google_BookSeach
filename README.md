## Google Book Search
## Description
A full-stack MERN application that allows users to search for books via the Google Books API. Users can create an account, search for books, and save their favorite books to their profile. The application uses GraphQL API with Apollo Server for efficient data fetching and manipulation. [1]

## Features
User authentication (signup/login)
Book search functionality using Google Books API
Save books to personal reading list
Remove books from reading list
Responsive design for mobile and desktop
GraphQL API for efficient data handling
Apollo Client state management

## Installation
Clone the repository:
git clone [repository-url]

- Install dependencies for both client and server:
cd client
npm install
cd ../server
npm install

- Create a .env file in the server directory with your MongoDB URI and JWT secret:

MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret

Start the development server:

- From root directory

npm run develop

## Usage
Create an account or log in
Search for books using the search bar
View book details including title, author, and description
Save books to your personal reading list
View saved books in your profile
Remove books from your saved list as needed
